# 2026-08-06

## 双指缩放灵敏度修复
- **问题**: GestureDetector 中 onTap + onScaleStart/Update/End 共享手势竞技场，导致双指缩放延迟明显、难以触发
- **方案**: 用 `Listener` 包裹播放器区域，直接监听原始 PointerEvent
  - `onPointerDown`: 记录所有手指位置，≥2 指时启动 pinch
  - `onPointerMove`: 根据双指距离比计算缩放，双指中点做锚点平移
  - `onPointerUp/Cancel`: <2 指时结束 pinch，接近 1.0 时自动归位
- **效果**: 完全绕开手势竞技场，双指缩放即时响应，放大后也能流畅缩小
- 文件: player_controller.dart (PlayerGestureControlMixin), live_room_page.dart (Listener wrapper), player_controls.dart (移除 onScale*)
