### 真正根因(编译错误)
- **flutter_screen_recording 2.0.25(pub.dev 正式版)不存在 `startRecordScreenWithInternalAudio` 方法!**
- 此前 WebFetch 的是 putpin fork(master 分支)的 API,与 pub.dev 2.0.25 不一致
- 我的 `screen_recorder_service.dart` 调用了不存在的方法 → `flutter build apk` Dart 编译失败 → CI 打包失败
- 已下载 2.0.25 源码包确认:
  - 只有 `startRecordScreen`(无声)/ `startRecordScreenAndAudio`(麦克风音)两个方法
  - Android 音频源是 `MediaRecorder.AudioSource.MIC`,无内音录制
  - `stopRecordScreen` 调 `FlutterForegroundTask.stopService()`,因 fft service 从未启动会抛 ServiceNotStartedException(被包内 catch)→ 停止后返回空路径,但**文件仍正常保存到 Movies/ScreenRecordings**
  - 插件 build.gradle:compileSdk 35 / Kotlin 2.1.0 / jvmTarget 17,与项目工具链兼容
  - 依赖 HBRecorder(jitpack)+ appcompat 1.6.0,CI 需访问 jitpack.io
- flutter_foreground_task 9.1.0 依赖干净(plugin_platform_interface ^2.1.8 / shared_preferences ^2.5.3 / platform ^3.1.6),其 manifest 需 app 手动声明 ForegroundService(但 2.0.25 从不启动它,可不声明)
- media_kit 1.2.2 依赖 web ^1.1.0 不依赖 js 包 → 与 flutter_screen_recording_web 的 js ^0.7.1 无冲突 → CI pub get 可成功
